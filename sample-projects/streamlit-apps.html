Reddit Scanner Streamlit Python App

Scans specific reddit channels for updates going from 1-7 days.

Description

The app scans two subreddits - r/bsmd and r/premed. User can specify additional subreddits to scan in a user input field. The app can display updates from 1 - 7 days based on user input. The app lists the update and user can choose to click read post, to be taken to reddit to look at the updates and comments in detail.
